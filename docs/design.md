# VALUE / SHIFT — design

Task: reference-value-tutorial-20261116. Authorized: Korean interactive tutorial and public GitHub Pages deployment. Never use Sites hosting.

An independent, dependency-free JavaScript application inspired by Fowler's Change Reference to Value. Main teaching model: two café products share a price object; mutation changes both, replacing an immutable Money changes one owner's field. This is an educational extension of the catalog's Product/Money code, not a quotation of the book. Café price tags remain the single analogy. Value objects can still be shared by JavaScript reference; equality is explicitly amount AND currency. Identity comparison and Array.includes do not invoke equals. Product itself remains an entity; don't convert identity/lifecycle objects blindly. Isolated-price calculations remain equal before/after; shared alias side effects and identity intentionally differ, so do not claim universal behavior equivalence.

Experience: six URL-addressable screens: introduction, sharing experiment, value replacement experiment, equality bench, six-question practice, code/takeaway. Hero uses a luminous mint price card linked to two product cards against deep forest, with large editorial Korean typography and warm ivory body. Mobile single-column and keyboard/reduced-motion accessible. No image-generation or external fonts needed; diagram is semantic HTML/CSS. Non-programmers start with visual changes, then minimal JavaScript.

JavaScript source: entry wiring; screen classes; Router, VersionService, ContentService, LabStorageService; pure domain; shared DOM/routes. CSS tokens/base/components. Draft forms require Apply or Cancel; save progress separately, failed saves stay dirty. Router protects edits and saves during normal navigation, browser history, and updates. Deep links use hash routes for native GitHub Pages 404 correctness. Build identity embedded in HTML, all JS/CSS build-named, version endpoint fresh; next safe navigation changes full document including hash target. Focus/pageshow only detect. Content fetch abort/race protection. No service worker.

Sources: https://refactoring.com/catalog/changeReferenceToValue.html and https://martinfowler.com/bliki/ValueObject.html . No invented commercial app adoption claim.

Acceptance: actual shared mutation versus replacement; equality by amount/currency; input validation/zero/repeated discounts; every lesson deep link/Back/Forward; 390/1440 responsive and keyboard; HTTP failures/retry/stale requests; update A→B, rollback, dirty and saves protection, failure fallback; real Pages assets/build verification.
